# CodeMonkey.UI.Rendering Index

> A specialized library for processing markdown and converting it into structured UI components.

## 📐 Interaction Map
`CodeMonkey.UI` ➡️ **`CodeMonkey.UI.Rendering`**

## 🔄 Common Workflows
* **Adding a New Markdown Element**:
  1. Define the data structure in `Models/`.
  2. Implement the parsing/conversion logic in `Services/`.

## 📂 Directory Mappings
* **`Models/`**: Data structures for decomposed markdown.
* **`Services/`**: Logic for rendering markdown elements.

## 📜 Local Rules & Conventions
* Rendering logic must be independent of the final UI framework to ensure portability.
